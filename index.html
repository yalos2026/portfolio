About me

Skills and tools

I work on both the interface people use and the code that runs on the server.

⚙️

Web development

  • Backend: PHP, Python and MySQL for application logic and database design.
  • Frontend: HTML, CSS and JavaScript, including animation with the Canvas API.
  • Infrastructure: Linux, Nginx, hosting and domain setup. MikroTik administrator certificate (2026).
🤖

AI-assisted content

  • Images: I use Gemini and ChatGPT to generate illustrations, edit photos and develop logo concepts.
  • Video: I use tools such as Google AI Studio to create and edit clips.
  • Writing: I use language models to draft presentations, website copy, scripts and translations.
🎨

Interface design

  • Plan page layouts and the steps visitors take to complete a task.
  • Build animations, interactive controls and browser games.
  • Design for mobile screens and tune page performance.
  • Build progressive web apps and work with FlutterFlow.

How I work

01

Define the task. I start by asking who the site is for and what they should be able to do there.

02

Decide what to build. I choose a layout and features that fit the content, then write the code rather than starting with a site builder.

03

Prepare for launch. I can handle the site copy, server configuration and deployment as well as the design and development.
